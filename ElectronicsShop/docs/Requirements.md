# Требования задания

Основание: страницы 16-17 методички «04. EF Core. Database First..pdf».

| Требование | Где реализовано |
| --- | --- |
| Менеджер входит по ПИН 1234, неправильный ПИН вызывает сообщение | `LoginWindow`, `Auth.Login` |
| Вход посетителя по кнопке | `LoginWindow.Visitor_Click` |
| Просмотр товаров | `MainWindow`, `ProductEditorWindow` в режиме просмотра |
| Поиск по наименованию | `MainWindow.RefreshFilters`, `InputRules.Matches` |
| Совместные фильтры категории, бренда и цены | `MainWindow`, `InputRules.TryPriceRange` |
| Сортировка наименования, цены и остатка в обоих направлениях | `MainWindow.ApplySort` |
| Добавление, просмотр, изменение и удаление товаров | `ProductEditorWindow.Save_Click`, `MainWindow.Delete_Click` |
| Добавление, просмотр, изменение и удаление категорий | `DictionaryWindow`, `NameEditorWindow`, ветка `categories` |
| Добавление, просмотр, изменение и удаление брендов | Те же окна, ветка `brands` |
| Добавление, просмотр, изменение и удаление тегов | Те же окна, ветка `tags` |
| Изменение доступно только менеджеру | Кнопки скрыты от посетителя, каждый обработчик записи проверяет `Auth.CheckManager` |
| Связь товаров и тегов многие-ко-многим | Таблица `product_tags`; в форме можно выбрать несколько тегов |
| Все поля обязательны, теги можно не выбирать | `IsValid`, `InputRules.CheckProduct`, SQL NOT NULL/CHECK/FK |
| Проверка цены, рейтинга, целого остатка и даты | `ProductEditorWindow.IsValid` |
| Счётчики всех товаров и результатов фильтра | `InfoProducts` и `InfoShown`, обновляются в `RefreshFilters` |
| Шаблон карточки из методички | Наименование, рейтинг, категория, описание, теги, цена и остаток |
| Жёлтая граница, если остаток меньше 10 | `IsLowStock`, цвет #ffd129 |
| Требуемые цвета | `App.xaml`: #dfeaeb, #00C4B4 и #00b4c4 |
| Заголовки всех окон | `Title` и видимые заголовки в XAML |
| Подтверждение необратимых действий | Удаление, сохранение изменений и закрытие несохранённой формы |
| ER-диаграмма PDF | `docs/ER_Diagram.pdf` |
| Скрипт восстановления схемы и данных | `database/Restore.sql` |
| Исходный проект | `ElectronicsShop.sln`, `src/` |

В коде используется стиль [примера pract8_TRPO](https://github.com/bakaqqw/pract8_TRPO): коллекции в коде интерфейса, `DataContext = this`, обработчики `Create_Click`, `Save_Click`, `GoBack_Click`, обычные `if`, `foreach` и явно указанные типы при создании объектов. Основание — исходники из `prakt8_wpf-main.rar`, коммит `3804b1aa8590debd5f6425172476d9d80f1f5b9a`.

Окна магазина открываются отдельно. Формы построены на `Grid`, `StackPanel`, `Label` и стандартных полях Material Design. Работа с SQL Server остаётся через EF Core Database First, как требует задание.

Минимальный размер каталога 960 × 640, формы товара 800 × 620 логических пикселей. Списки и многострочное описание прокручиваются. Проверка фактического отображения при разных масштабах Windows выполняется на целевом компьютере.
